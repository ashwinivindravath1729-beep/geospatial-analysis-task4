# Geospatial Data Analysis - Task 4

## Project Overview
Analyze location-based data to identify optimal areas 
for business expansion. Visualize sales data geographically 
and detect regions with high demand but low presence.

## Analysis Performed
1. Existing store performance analyzed
2. Sales breakdown by state
3. High demand regions identified
4. Expansion score calculated for each region
5. Top 3 new store locations recommended

## Key Findings
- New York & California have highest sales
- Seattle, Brooklyn & Austin are top expansion targets
- High income + high demand = best expansion formula
- Avoid areas with 5+ competitor stores

## Recommended New Locations
1. Seattle, WA - Expansion Score: 58.8
2. Brooklyn, NY - Expansion Score: 57.9
3. Austin, TX - Expansion Score: 55.6
